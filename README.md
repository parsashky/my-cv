# 👨‍💻 Django Portfolio & Digital CV

Welcome to my personal portfolio project! This is a robust web application built with **Django**, designed to showcase my professional work, skills, and allow recruiters to download my latest CV directly.

---

## ✨ Key Features
- **Dynamic Content:** Projects and skills are managed via the Django Admin panel.
- **CV Download:** Integrated feature to download my resume in PDF format.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views.
- **Contact Form:** Functional contact section with email integration.
- **Secure Backend:** Built with Django's best practices for security and performance.

## 🛠️ Tech Stack
*   **Backend:** Python & Django 5.2.14
*   **Database:** SQLite (Development) / PostgreSQL (Production)
*   **Frontend:** HTML5, CSS3, JavaScript (Optional: Tailwind/Bootstrap)
*   **Deployment:** [e.g., Gunicorn, WhiteNoise, Vercel/DigitalOcean]
